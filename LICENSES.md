# Licences

## Project code

All first-party code in this repository is owned by the Airside project (Bailey
Fleming). No public licence is granted yet; the repository is private.

## External assets and data

The authoritative register is
[`docs/data/ASSET_AND_DATA_REGISTER.md`](docs/data/ASSET_AND_DATA_REGISTER.md).
Every external asset, dataset, image, sound, font or piece of third-party code
must be recorded there — with owner/source, use, licence, attribution and
evidence — **before** it enters a distributable build. Unknown rights block
public release.

As of the latest update the project includes third-party **data** as well as art and audio, each recorded in the
register with its licence and the credit shown in the game (Flight Manual › Map and data credits):

- **OpenStreetMap** © OpenStreetMap contributors (ODbL 1.0): airport layout, roads, car parks, buildings, coast, land use.
- **Copernicus Sentinel-2** ("Contains modified Copernicus Sentinel data") and **Copernicus DEM GLO-30**
  (© DLR e.V. and © Airbus Defence and Space GmbH, provided under COPERNICUS by the EU and ESA): satellite tint,
  terrain height and derived tree positions.
- **Natural Earth** and **OurAirports** (public domain): the route map.
- **Open-Meteo** (CC BY 4.0) and **adsb.lol** (ODbL): live weather and traffic.
- **CC0 textures, characters and audio** (ambientCG, Poly Haven, Quaternius, qubodup and others).

The project depends on the Unity engine and packages under Unity's own terms (to be reviewed at release). A
public release needs the credits screen checked against the register first.

## AI-assisted development

Generated code, images, audio and 3D assets are reviewed like human work and
their origin recorded. Do not ask a model to imitate a living artist, reproduce
airline liveries, or reconstruct proprietary assets.
