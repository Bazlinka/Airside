## Biggest mismatches

**Correct seating, weak cabin identity.** `PassengerCabinProfile.cs:27` already selects 2+4+2, unlike A359's 3+3+3 at line 26. Airbus confirms typical A330 economy 2-4-2; this is representative, not compulsory for every operator. However `PassengerCabinInterior.cs:38–47,70–72` builds a 3.95 m section with flat ceiling/walls, end bulkheads, uninterrupted box bins and generic centre boxes. Looking inward can reveal an artificially short room instead of a widebody cabin.

**Seat pitch incorrectly determines window repetition.** `PassengerCabinInterior.cs:94–114` applies identical 0.32 × 0.44 m elliptical openings to every type and repeats at seat pitch (0.79 m here). A339 exterior inherits A350 window geometry: `scripts/generate-air-adelaide-fleet.py:272–280`; donor windows are 0.25 × 0.36 m at 0.508 m spacing before scale (`scripts/generate-air-009-a350-900.py:107–120`). These are model dimensions. Hiding the hull (`CockpitInterior.cs:25–37`) avoids occlusion but disguises interior/exterior inconsistency. The old A339 window tiles visibly show faceting and rectangular dark corner areas; their cause needs future runtime inspection rather than diagnosis from a thumbnail.

**A330neo is not an A350 with narrower seats.** The generator scales A350 wing/gear/engines and substitutes a rounder nose; `generate-air-adelaide-fleet.py:317–326` explicitly replaces glazing with four panes. Interior quarterlight pillars remain (`JetCockpitInterior.cs:120–130`), so both views need one agreed pane map.  Airbus confirms Trent 7000 power and A350-inspired winglets: shared inspiration supports reuse, not identical nacelle or wing geometry. The classic display arrangement is a good starting point (`JetCockpitProfile.cs:29`, `JetCockpitInterior.cs:162–177`); changing to the A350's large-screen arrangement would weaken identity.

## Acceptance and configuration discipline

Implementation source checks should verify eight seats/two aisles, independent window stations, bounded curved shell continuity, matched pane topology across interior/exterior and no donor-named geometry silently treated as measured A330 geometry. Preserve renderer restoration, wing/engine visibility and material batching. None of those checks was executed in this audit.

Future native and packaged review must capture forward/overhead/footwell, left/right window plus inward glances, exterior front/side/orbit, day/dusk/night and rain, using the same A339 registration. Inspect shade/reveal corners, bin curvature, row continuity, wing sightline, HUD clearance and all four switches; record actual frame time. This review has not occurred here.

Airbus cabin offerings vary. Its current improvements article schedules electro-dimmable windows between Doors 1 and 2 among changes through 2028; this does not establish universal installed dimming today. Keep baseline mechanical shades unless a selected configuration is evidenced. HUD/harmonised-PFD/EFB offerings likewise do not justify adding functional avionics. Airbus's cockpit page illustrates an A330-800: useful family architecture reference, not a certified A330-900 operator cockpit replica.
