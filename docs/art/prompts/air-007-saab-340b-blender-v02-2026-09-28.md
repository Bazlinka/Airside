# AIR-007 Saab 340B Blender v02 candidate — 28 September 2026

## Status

**Generated / Modelled candidate. Not approved, integrated, or runtime.**

This is the first controlled Blender pilot for Airside. It proves that the
existing project-owned Saab can be brought through an editable DCC workflow
without changing simulation behaviour or silently replacing the Unity asset.

## Required task packet

- **Player-visible outcome:** a more convincing starter-aircraft close view,
  led by twisted/tapered four-blade propellers, cleaner material separation,
  intake lips and restrained undercarriage detail.
- **Files in scope:** the v02 candidate under
  `docs/art/candidates/air-007-saab-340b-v02/`, its deterministic Blender build
  script, this evidence note, the asset register and the `GAME.md` handoff.
- **Relevant invariants:** simulation owns state and timing; metres and the
  current AIR-007 envelope stay exact; moving-part names and pivots stay
  animation-compatible; the current v01 remains the fallback and runtime art.
- **Acceptance criteria:** 19.73 m length, 21.44 m standard span and 6.97 m
  height; tyre contact at zero; named props, controls, doors and gear retained;
  prop pivots at the hubs; FBX and GLB exports; multi-view and close-up renders;
  no unlicensed source art; bounded geometry growth.
- **Checks:** deterministic script validation, Blender GLB round-trip, existing
  AIR-007 geometry test and aircraft connectivity test. A packaged Unity
  overview/follow comparison and measured FPS remain mandatory before any
  runtime promotion.
- **Must remain unchanged:** gameplay, saves, schedules, movement, liveries,
  existing runtime files, thumbnails and primitive fallbacks.

## Source and method

- Editable source: the project-owned, ADR 0150 enamel/livery-finished
  `game/Airside/Assets/Airside/Art/Models/Aircraft/mdl_saab_340b_v01.fbx` from
  merged PR #422.
- Tool: Blender 5.2.2 LTS, driven by
  `scripts/build-air-007-blender-v02.py`.
- External references are factual only: the [Saab 340 product page](https://www.saab.com/products/saab-340)
  and [EASA type-certificate page for EASA.A.068](https://www.easa.europa.eu/en/document-library/type-certificates/aircraft-cs-25-cs-22-cs-23-cs-vla-cs-lsa/easaa068-saab-sf340a).
- The candidate preserves ADR 0150's project-owned original paint geometry. No
  external mesh, texture, logo, registration, airline livery or image was copied
  into it.
- Licence: project-owned procedural/modelled geometry. Cost: $0. Attribution:
  none required. Fallback: the current AIR-007 v01 runtime kit.

## Measured result

- Exact Blender-space dimensions: **21.44 × 19.73 × 6.97 m** (span × length ×
  height), with tyre contact at Z=0.
- ADR 0150 source import: **57,333 triangles**. Candidate: **60,445 triangles**,
  **+3,112 / +5.43%**. The script fails if candidate growth exceeds the bounded
  review budget.
- **149 mesh objects** with the existing runtime-facing propeller, control,
  door and gear names retained.
- Each replacement blade and safety-tip object has its origin at the correct
  left or right propeller hub.
- GLB round-trip preserved required names and the exact aircraft envelope.

This triangle count is a candidate comparison, not a performance claim. Before
promotion, the asset still needs Unity import settings, LOD/collider decisions,
the existing animation hooks, packaged overview/follow visual QA, and measured
before/after frame performance with multiple aircraft visible.
