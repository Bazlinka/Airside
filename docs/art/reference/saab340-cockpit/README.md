# Saab 340B cockpit visual reference, 1 October 2026

Bailey requested rebuilding the generic first blockout into a recognisable,
gamified Saab cockpit. This is original procedural 3D geometry, using real
flight-deck photographs for layout and proportion observations.

Primary references inspected: C&L Aerospace aircraft specifications, page 3:
- [Saab 340B-447, 10 September 2020](https://cla.aero/wp-content/uploads/2020/09/SAAB340B-447-Specs-10Sept2020.pdf): frontal panel, yokes, pedestal.
- [Saab 340B-331, 2018](https://cla.aero/wp-content/uploads/2018/08/SAAB340B-331-Spec-Sheet-16Aug2018.pdf): full panel, overhead and windscreen.

The seller identifies these interior photographs as indicative. They establish
visible layout, not surveyed dimensions or an exact aircraft equipment fit.
PDFs and local review-page renders are scratch under `work/cockpit-reference/`;
no third-party photograph, copied marking, logo or texture is shipped or committed.

Secondary discovery: [Bidgee's Rex VH-TRX Saab 340B photograph](https://commons.wikimedia.org/wiki/File:Cockpit_of_Regional_Express_Airline%27s_(VH-TRX)_SAAB_340B_(2).jpg),
CC BY-SA 3.0 AU. Its file could not be loaded by the browser; therefore it is not
claimed as a visually inspected modelling source.

## Features carried into the game

- Raked paired forward windscreens, angled quarter windows, thinner seals/posts.
- Warm ivory lining and grey instrument panel with a chamfered silhouette.
- Two vertically stacked small CRT-style flight displays for each pilot.
- Round instruments beside those displays, and paired central engine gauges.
- Shallow glare shield with a separate guidance/autopilot button rail.
- Squared yokes, pale columns, checklist clips; no airliner steering wheel.
- Narrow radio pedestal with three paired lever groups and an overhead switch panel.

The dials and EFIS graphics are illustrative decoration. Existing local ground
speed, height above runway datum and heading remain live in a small central
readout. This does not claim functioning avionics, flight controls or measured
Saab cockpit dimensions. Simplification targets Airside's miniature style.
