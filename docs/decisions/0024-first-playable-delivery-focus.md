# Decision 0024 First playable delivery focus

**Date:** 2026-09-07  
**Status:** Accepted by Bailey

## Decision

Make the macOS first playable the only active product target. Use the systems and integrated assets already in the repository. Pause new platforms, major simulation layers and broad asset batches until a short external playtest proves the first session is understandable and enjoyable.

Replace the comprehensive product blueprint with a shorter execution plan that names the current blocker, the next implementation slice, its acceptance criteria, the delivery sequence and a deferred backlog.

## Reason

The project has accumulated enough simulation, economy and presentation work to support a first playable. Continuing parallel planning and content production would delay the point at which a new player can test the central loop.

## Affected systems

Product planning, task selection, art production, Mac build verification and external playtesting.

## Migration impact

No runtime or save migration. Long-term ideas remain deferred rather than removed from the product direction.
