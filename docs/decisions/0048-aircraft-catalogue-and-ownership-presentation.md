# 0048 — Aircraft catalogue, Hangar types and player/AI presentation

Date: 2026-09-15. Next milestone after ADR 0047 in Bailey's approved priority order:
"add the reusable aircraft catalogue and Hangar presentation".

## Decision

1. **One catalogue.** `Domain/AircraftCatalogue` holds every type's name, role, real
   dimensions, planning cruise, practical range, manufacturer cruise/range, stand class
   (regional bay or terminal gate), model status (genuine or placeholder), runtime model and
   thumbnail paths and a source id. `AircraftType.Atr42/Saab340/Dash8Q400/Boeing7378` are now
   properties returning the catalogue's instances (no static-init cycle), `TryFromId` reads
   the catalogue and `AirlineOperations.NeedsTerminalGate` reads the stand class. UI code
   reads the catalogue instead of its own constants.
2. **Cited facts, labelled assumptions.** Figures and URLs are in
   `docs/data/AIRCRAFT_SPECIFICATIONS.md`. Planning cruise and range stay at or below the
   manufacturer figure where one exists (tested). The Dash 8-400's practical range drops from
   1,800 km to 1,500 km, under De Havilland's 1,596 km full-passenger range; QantasLink's
   network (PLO, ASP) stays reachable, so regional traffic is unchanged. Saab 340B range and
   737-8 cruise are marked as assumptions until a manufacturer figure is recorded.
3. **Thumbnails from the runtime model.** `scripts/render-aircraft-thumbnails.py` reads each
   genuine runtime glTF and renders one consistent, unbranded three-quarter view (480×320,
   transparent, neutral part colours) into `Art/UI/Aircraft/` (synced to StreamingAssets).
   Placeholder types (Saab 340B, Dash 8-400) have **no** model or thumbnail path and the
   Hangar shows a labelled "PLACEHOLDER" box — never the ATR image.
4. **True-scale check.** `AircraftModelBounds` measures runtime glTF bounds; tests require
   ±5% of the catalogue dimensions (ATR 42-600 and AIR-005 both pass).
5. **Hangar.** Tabs: *Fleet* (YOUR AIRLINE, then OTHER OPERATORS grouped by airline) and
   *Aircraft types* (one card per catalogue type: thumbnail or placeholder, role, dimensions,
   planning cruise and range, stand class, how many fly at Adelaide and how many are yours,
   model status).
6. **Player/AI distinction everywhere** via `Presentation/Ownership`: the same section names,
   the player's livery accent bar and "YOURS" badge, and AI traffic at 62% opacity — in the
   Hangar, fleet panel, Flights board (now split into the two sections, time order kept
   within each), route map (AI icons smaller and fainter), field tags (player tags carry the
   badge and a livery frame) and the selection card ("YOURS" or "OTHER OPERATOR"). Layout
   is otherwise unchanged.

## Migration

None. No save-schema, simulation timing or stand change; the Dash 8-400 range change only
affects which legs are reachable, and every leg QantasLink flies remains reachable.
