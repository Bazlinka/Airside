# 0221 — Control tower outward-canted cab

Date: 2026-10-01 · Owner: Cursor

**Decision:** restyle the Adelaide Airport Control Tower cab as an
outward-canted glazed ring (stacked lower/upper glass prisms, wider on top)
with a clear cab floor slab and a roof that overhangs the outer glass
(`BuildingDetail.AddTower`). Surveyed height stays **44 m**. Presentation only.

**Reason:** Phase 3 airside accuracy — the tower already had the right height
but read as a shaft + inset box. Canted cab is the ATC silhouette without new
assets or Bailey photos.

**Affected systems:** `BuildingDetail` tower presentation.
**Migration impact:** none.
