# Passenger and exterior aircraft views

Player outcome: select any of the ten passenger jets or three turboprops, enter a
left/right window seat, and switch between cockpit, passenger and outside views
without losing the selected aircraft or regional terrain. Outside view orbits the
flying aircraft, with scroll-controlled distance. Overview/Esc releases the journey.

Scope: camera controller, existing spectator lifecycle/selection card, fitted
PassengerCabinProfile/Interior, audio listener routing and focused native review.
Presentation only: no flight controls, bookings, progression or save schema changes.
World coverage remains that of the existing South Australia terrain; interstate
coverage and the inherited long-flight stall are not extended by this task.

Authenticity: original simplified five-row cabin section fitted to each existing
kit's window station. SF34 1+2, ATR42/DH8D/E190 2+2, A223 2+3, B737/A320 family 3+3,
A339 2+4+2, A359/787 3+3+3 representative economy layouts. Configurations and seat
pitch vary by operator; this is not a replica of a particular airline's cabin.
Opaque window apertures reveal the aircraft's actual wings/nacelles/animated props.
Cabin surfaces combine into one mesh per material; only the selected interior exists.

Acceptance: all 13 types have both window views; unobstructed window sightlines;
external shell/renderer state restores on switching/exiting/destruction; exterior
camera tracks the aircraft through origin changes; camera optics restore on exit;
no distant-world reset when switching view mode; interior audio only inside.
Native rendered review covers left/right/cabin/outside for all types. A short
packaged review checks the actual flight-view HUD and switching before handoff.
